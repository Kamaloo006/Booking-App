# BookIT 🏠

**BookIT** is a modern property management platform built to simplify renting and listing real estate. It offers a clean, secure, and efficient experience for both property owners and renters.

---

## Features

### Authentication & Roles

* Multi-role access for **Owners**, **Renters**, and **Administrators**
* Secure authentication and authorization system

### Property Management

* Full CRUD operations for property listings
* Upload and manage high-quality images
* Add detailed property descriptions and specifications

### Search & Filtering

* Filter by:

  * Property type (House, Villa, Apartment)
  * Price range
  * Location
  * Amenities

### User Dashboard

* Manage property listings
* Track user inquiries
* Update profile information in real time

### Security

* Backend secured with Laravel middleware
* Strong API protection and validation layers

---

## Tech Stack

* **Backend:** PHP 8.x, Laravel
* **Database:** MySQL
* **Authentication:** Laravel Sanctum
* **Frontend:** Flutter
* **Version Control:** Git & GitHub

---

## Summary

BookIT focuses on delivering a reliable and scalable solution for real estate management with strong security, smooth user experience, and efficient data handling.
