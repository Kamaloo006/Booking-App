# ------------ BookIT 🏠

A professional property management platform designed to streamline the process of renting real estate. This application provides a seamless experience for both property owners and seekers with a focus on security and performance.

---

## 🚀 Core Features

- Multi-Role Authentication: Dedicated dashboards for Owners, renters, and Administrators using advanced authorization policies.
- Property Management: Complete CRUD functionality for property listings, including high-quality image uploads and detailed specifications.
- Advanced Search & Filtering: Filter properties by category (House/Villa/Apartment), price range, location, and amenities.
- Interactive User Dashboard: Manage listings, track inquiries, and update profile information in real-time.
- Secure Backend: Robust API and web security implemented via Laravel’s middleware and protection layers.

## 🛠 Tech Stack

- Backend: PHP 8.x & [Laravel Framework](https://laravel.com)
- Database: MySQL
- Authentication: Sanctum
- Frontend: Flutter (Frontend Team)
- Version Control: Git & GitHub
